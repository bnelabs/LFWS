# LupaFrame website

Product website for LupaFrame, a 3D consultation viewer in development for clinics and private practices.

[Live website](https://bnelabs.github.io/LFWS/)

## Local preview

Run `python3 -m http.server --bind 127.0.0.1 8000` from the repository root and open [the local preview](http://127.0.0.1:8000/).

The site uses [DM Sans under the SIL Open Font License](fonts/OFL.txt).
